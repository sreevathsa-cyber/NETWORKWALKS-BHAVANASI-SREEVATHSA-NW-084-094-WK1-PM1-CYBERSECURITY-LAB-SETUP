# Verification Checklist

Mark an item complete only after performing and observing the test.

- [ ] Kali installer completed successfully
- [ ] Kali VM restarted successfully
- [ ] Kali desktop/login screen reached
- [ ] Kali release recorded
- [ ] VirtualBox network adapter mode recorded
- [ ] Guest interface identified with `ip a`
- [ ] Default route checked with `ip route`
- [ ] DNS resolver checked
- [ ] DNS resolution tested
- [ ] Gateway connectivity tested (if ICMP is allowed)
- [ ] Shared folder configured and guest access verified (if required)
- [ ] Baseline VM snapshot created (if required)
- [ ] Screenshots added and reviewed for sensitive information
- [ ] README placeholders completed
