# NetworkWalks Week 1 – Project 1 Submission Checklist

The supplied NetworkWalks instructions specify four steps:

## Step 1 – GitHub or Google Drive (GitHub recommended)
- [ ] Create a new repository for this project.
- [ ] Follow the sample repository naming format.
- [ ] Add this `README.md`.
- [ ] Upload your project screenshots and supporting documentation.
- [ ] Confirm the repository is accessible to the intended reviewers.

Suggested repository name format from the instruction image:
`NETWORKWALKS-[YOUR-NAME]-[YOUR-ID]-WK1-PM1-CYBERSECURITY-LAB-SETUP`

Replace the bracketed fields with your own correct name and assigned ID. Do not copy another participant's name or ID.

## Step 2 – LinkedIn
- [ ] Write a short post describing what you built and learned.
- [ ] Tag `@NETWORKWALKS`.
- [ ] Tag your instructor `@WAQAS KARIM CCIE` using LinkedIn's mention picker.
- [ ] Use `#Networkwalks`.
- [ ] Put the GitHub repository URL in the first comment, not in the post text.
- [ ] Do not include IP addresses or links in the LinkedIn post text.

## Step 3 – Troubleshooting experience
- [ ] Describe one real issue faced during the project.
- [ ] Explain the checks and steps used to resolve it.
- [ ] State how the fix was verified.
- [ ] If no issue occurred, help another participant by answering their question in comments.

## Step 4 – Submit the form
- [ ] Open the official NetworkWalks project submission form shared by the program.
- [ ] Enter the requested details and links.
- [ ] Submit and save the confirmation for your records.

**Important:** This repository package does not submit the form or publish the LinkedIn post for you.
